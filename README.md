# 大模型质量探测器

一个检测 API 中转商是否"以次充好"的 Web 工具，纯前端单 HTML 文件。

## 功能特点

- **11 道预置测试题**：从多个维度检测模型真实能力
  - 语义理解（1题）
  - 逻辑推理（4题）：竹竿过门、洗车悖论、24点、密码锁
  - 身份探测（2题）：直接探测、JSON自述
  - 代码能力（3题）：macOS模拟器、Trello看板、3D平面图
- **自由选择代码题**：想测哪道勾哪道
- **手动评分**：可调整自动评分
- **代码预览下载**：自动提取代码并支持下载

## 使用方法

1. 打开 `index.html`
2. 填写 API Base URL 和 Key
3. 选择模型（或手动输入）
4. 勾选要测试的代码题
5. 开始测试，查看报告

## 技术栈

- 纯 HTML + CSS + JavaScript
- 流式 SSE 调用
- OpenAI 兼容协议
